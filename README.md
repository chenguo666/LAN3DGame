# LAN 3D 射击对战游戏

一款基于 **Three.js + Node.js** 的局域网 3D 多人射击游戏。玩家可以在大厅中选择一把近战武器和一把远程枪械，进入同一张地图进行对战。

## 功能特性

- 🔫 局域网多人对战（WebSocket 实时同步）
- ⚔️ 近战武器：战术匕首 / 消防斧 / 武士刀
- 🔫 远程枪械：手枪 / 霰弹枪 / 突击步枪 / 狙击步枪（一枪毙命，右键开镜）
- 🎯 命中检测、弹道轨迹、枪口后坐力、换弹系统
- 🩸 生命值、击杀/死亡战绩、实时排行榜（Tab 键）
- 🧱 掩体系统（可阻挡子弹与近战挥砍）
- 🗺️ 更丰富的地图：集装箱掩体、中央直升机坪、出生区、路标、动态天空与实时阴影
- 🔊 使用 WebAudio 实时合成音效，无需音频文件
- 🕹️ 第一人称视角 + 指针锁定（Pointer Lock）

## 运行方法

1. 安装 [Node.js](https://nodejs.org/)（版本 12 或更高，推荐 16+）。
2. 打开命令行，进入本文件夹：

   ```bat
   cd /d C:\LAN3DGame
   ```

3. 启动服务器：

   ```bat
   node server.js
   ```

    也可以直接双击 `start.bat` 启动。

4. 本机游玩：浏览器打开 `http://localhost:3000`。
5. 局域网其他玩家：先查看本机局域网 IP（例如 `ipconfig` 中的 `192.168.x.x`），然后在其他电脑浏览器打开：

   ```
   http://<本机局域网IP>:3000
   ```

6. 默认端口为 `3000`，可通过环境变量修改，例如：

   ```bat
   set PORT=8080 && node server.js
   ```

## 关于 Three.js 加载

游戏默认从 CDN 加载 Three.js（jsDelivr / unpkg）。如果你的局域网玩家无法访问互联网，请手动下载：

```
https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js
```

或者在服务器上执行 `node download-three.js` 自动下载（需要服务器能访问互联网）。

并将文件放到：

```
public\js\vendor\three.min.js
```

然后刷新页面即可（代码会自动回退到本地文件）。

## 常见问题

- **无法连接**：请检查防火墙是否放行 `3000` 端口，或暂时关闭防火墙测试。
- **其他玩家加入后看不见人**：确认所有玩家都在同一网段，并且使用的是 `http://<服务器IP>:3000`，而不是 `localhost`。
- **页面提示引擎加载失败**：说明 CDN 与本地文件都不可用，请按上方说明下载 `three.min.js`。
